Architecture: reason offline, execute exactly

site/diagram.png (submitted 12:00) · replica live at blackbox.rubrica.dev

0:15–0:45. We split reasoning from execution. Offline, a person and a model propose hypotheses. The harness requires a prediction and records every request. At runtime, a serial server applies versioned rules. The first match decides; no model call, and no call to the original.
