THE APPROACH

Discover slowly, run fast, keep one source of truth

OFFLINE

System 2

A person and a reasoning model probe the original through a harness. Every request is recorded with its hypothesis and prediction.

MEMORY

Ontology

Versioned rules with evidence and confidence: confirmado, probable, supuesto.

RUNTIME

System 1

The replica: a compiled rule table. The first matching rule decides. No model at runtime.

Source: docs/DESIGN.md §3

Kahneman's terms. System 2 is the slow, deliberate discovery loop. System 1 is the fast replica. The exact judge for every probed behavior is the original service itself, so we never need an LLM judge.
